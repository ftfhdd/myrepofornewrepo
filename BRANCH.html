command for branch creation git branch git checkout -b to create and switch to the branch git checkout to switch to the branch git push -u origin to push the branch to the remote repository git merge to merge the branch to the current branch git branch -d to delete the branch git branch -D to force delete the branch git branch to list all the branches git branch -a to list all the branches including remote branches git branch -r to list all the remote branches git checkout -b origin/ to create a local branch from a remote branch git pull origin to pull the changes from the remote branch to the local branch git push origin to push the local branch to the remote branch git merge to merge the branch to the current branch git rebase to rebase the branch to the current branch git cherry-pick to apply the changes from a specific commit to the current branch git stash to save the changes in a stash git stash pop to apply the changes from the stash and remove it from the stash list git stash list to list all the stashes to create a branch from a specific branch git checkout -b
