COMMANDS to reset the commit and restore the commits undo commands git reset filename to unstage the file git reset --soft HEAD~1 to undo the last commit but keep the changes in the staging area git reset HEAD~1 to undo the last commit and unstage the changes git reset --hard HEAD~1 to undo the last commit and discard the changes git reset --soft to reset to a specific commit but keep the changes in the staging area for multiple commits git reset --COMMIT_HASH to reset to a specific commit and discard the changes git reset --hard to reset to a specific commit and discard the changes git reset --soft to reset to a specific commit but keep the changes in the staging area
